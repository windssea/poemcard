# 风过诗廊设计与开发规划

最新界面优化采用保留式设计审视，底部入口集中为纸面浏览带，提升触控、对比度、键盘收起和加载提示。详情见 ui-design-review.md；界面结构与视觉样式已整理，视频继续无独立边框。

风过诗廊是一座可探索的临水国风诗画庭院。React 管理阅读与环境选择，Three.js 负责实时光影、水面反射和风动书签。内容与素材按诗词独立组织，新增诗词无需修改场景组件。首阶段验证体验与渲染技术，后续用精细模型、材质和性能分档完善视觉。

## 当前红墙庭院构图

当前版本使用 scene-source/layers 的干净底图和透明近景枝花，近景以独立平面、局部风动形变和较大的视差幅度渲染，原图中的近景枝花不再保留以避免重影。全套界面采用本地毛笔字与宋体组合，详情见 scene-layers.md；原图右侧静态挂饰已从底图去除，交互书签统一由真实 3D 元素承担。

主页采用用户提供的 demo/bg.png，替换此前程序廊架场景。背景素材保留原画建筑、红墙、远山及右侧悬饰，黄色框仅用于布局定位，不进入产品。交互区域对应原图约 x=5%–71%、y=47%–88%。桌面每段最多 6 首，书签挂在左侧红墙单排展示；当前只有一首，居于交互区中央，不重复内容。

采用固定正交机位，背景图位于后方布景平面；实时阴影接收平面位于图像前；交互书签、纸边、木轴、玉环及独立流苏位于中景；花瓣位于更近的多个深度。鼠标只驱动轻微视差，不提供自由旋转。移动端背景向红墙区域偏移，保留可用的书签触控空间。素材图中的建筑、云山与原有悬饰是静态图像，不宣称为完整三维模型。

标题放在天空留白，寻诗与境候使用轻量纸色工具区，底部石地放置分页和当前诗名入口。之前的水面、程序树木及全屏光束不再叠加到新背景，以保留参考图的构图与质感。时辰和天气可调整图像整体色温，四季完整背景版本与独立景深分层素材待后续准备。

背景生成脚本为 scripts/prepare-scene.mjs，输出 public/scene/courtyard.webp，构建自动执行；当前入口为 Courtyard.tsx 和 CourtyardBookmarks.tsx。旧 Scene.tsx 保留供参考，不参与主页渲染。

## 混合场景动态层

远景使用原图布景与两层透明程序云雾，噪声以不同频率缓慢流动；红墙叠加低强度动态阴翳，书签在独立阴影接收层投射实时阴影；近景花瓣使用真实几何，具有多组深度、旋转、下落和阵风漂移；地面前方使用极淡的薄雾。鼠标视差幅度随层次增加，远云小、书签中、近景花瓣大，机位始终固定在主构图。

鸟以小尺寸身体和独立拍动双翼构成，约每42秒经过一次，飞行约10秒，完整画质下两只错位飞行，进出渐隐；减少动态偏好时不显示飞鸟并停止持续运动。轻量画质减少花瓣、降水和飞鸟数量，省略近地薄雾。雨雪天气使用相应降水粒子；季节调整前景花瓣或叶片色彩，原始建筑和背景树木仍保持提供素材，不宣称自动生成了完整四季画面。

书签与流苏共用连续阵风函数，保留独立运动相位。动画使用时间步长限制，后台暂停累计时间；打开诗画时庭院 Canvas 停止渲染，回到诗廊后恢复。动态模块为 src/scene/atmosphere/CourtyardAtmosphere.tsx，风场为 src/scene/animation/wind.ts。

构图从底部收紧约6%，保留顶部天空位置，减少地面占比。书签画心高度由桌面2.14增至2.65、手机1.7增至2.1，并上移挂点，确保流苏完整且不与底部入口重叠。缩放由固定正交镜头完成，不改写原始背景图片。

## 体验与随诗入境

场景使用固定主视角，每段桌面最多 6 首、手机最多 3 首，单排悬挂避免前后遮挡。每首诗只显示一次，左右按钮、键盘方向键或手机横滑切换分段。底部提供当前段诗名入口，书签悬停显示诗名与诗人；顶部寻诗支持按诗名、诗人、朝代筛选，搜索结果点击后定位分段并打开诗画。环境控制收纳至境候入口，减少场景遮挡。

场景只展示书签图。点击后读取该诗详情，展开完整主图；主图完成 450ms 展开动画后，再等待 500ms。视频可播放时淡入并静音循环。关闭、切换、组件卸载时暂停并移除视频地址。后台暂停视频。自动播放失败时保留主图和手动播放入口。首屏与悬停不请求视频，播放器只为当前诗词创建，不预取其他视频，不使用完整文件 Blob。

诗画打开后占满浏览器视口，默认仅显示读诗和关闭两个按钮。图片与视频使用居中 contain，保留完整画面与原始比例，竖版视频以窗口高度为主；窄屏空间不足时按宽度等比缩小。左右留白为浅色宣纸及木质画轴。宣纸纤维、茶染和木纹采用程序纹理，3D 材质为非金属、高粗糙度，配合木轴投影；背景使用按需渲染，不持续动画。点读诗进入独立的宣纸色阅读页面，显示诗名、朝代、诗人和原文，同时暂停视频；点观画回到同一播放器并继续播放，不重新创建视频或下载文件。阅读模式切后台再返回不会自动播放隐藏的视频。此全屏为网页视口，不主动切换操作系统全屏。

画卷为连续装裱结构：绢质底料两侧连接并包覆卷轴，宣纸贴在底料内，上下留天头与地脚，左右为装裱边；视频画心不设置独立边框、绫边或阴影，比例留白直接呈现宣纸。DOM 视频与 3D 装裱共用 scroll-layout.ts 的尺寸计算，避免装裱与播放区域错位。视频在装裱内部等比缩放，完整展示；读取视频元数据更新比例。播放与阅读均保留整张连续宣纸。

视口宽度达到900px时采用桌面并排画卷：左侧动画保持 contain 和原始比例，右侧直接显示诗名、朝代诗人、原文。标题和各行使用 vertical-rl，列按从右向左排列，DOM 保留诗名、诗人、原文的自然语义顺序。桌面无需读诗切换，视频持续播放。小于900px采用移动式观画与读诗切换，读诗暂停视频；回到宽视口自动恢复并排播放。长诗允许诗词区域滚动，避免将文字挤入动画区域。

宣纸采用确定性的程序晕染：边角淡茶染、不规则灰墨扩散、水渍沉积边和稀疏旧斑，与细纤维共同形成纸面质感。染色集中在边角，中央诗词区域留白；高粗糙度非金属材质保持哑光，手机读诗页沿用纸面纹理与轻染色。染色静态生成，不增加每帧动画开销。

当前画心使用极窄的程序残纸透明边缘，按原比例布局，边缘轻微不规则并淡入宣纸，不添加独立绫边或硬框。诗人印章从 poet 姓名生成朱砂色竖读印面，桌面放在署名下方，手机放在诗末。关闭、观画与读诗仅为透明毛笔文字，置于画卷上方装裱内，不使用按钮底色。根据最新视觉要求，所有界面文字及原文统一使用本地 Ma Shan Zheng 毛笔字体，并放大原先的小字号；Noto Serif SC 保留为备用资产。

每首诗具有 sceneHint，包含 season、timeOfDay、weather、windStrength 和 reason。开启随诗入境后，点击书签使用这组环境参数。推荐场景是艺术解释，不代表准确的历史创作天气。阅读关闭后保留入境环境，用户仍可手动调整。后续可添加“回到之前环境”。

## 场景与真实光影流水

场景围绕木构廊架、溪流、石岸、远山和植被展开。书签悬挂点独立，统一风场加不同相位。主光使用方向光和实时阴影，半球光提供环境填充，夜晚由月光和灯笼补光。纸张为高粗糙度材质，避免塑料光泽；木材和石材后续加入经过授权的 PBR 纹理与精细模型。

水面采用 Three.js Water 的平面反射渲染、动态法线和太阳高光。反射内容来自当前场景，可反射廊架与书签。当前使用周期性多尺度法线、统一方向的纹理漂移和雨天程序涟漪，改善原型的大幅反射扭曲。后续补充岸边泡沫、浅水深度颜色和随机雨滴位置。平面反射并非光线追踪，不模拟真实流体；当前水域通过两岸地形和石岸形成空间边界，仍需精细河床与河道网格。

四季控制植被、地表和水色；时辰控制天空、主光和灯笼；天气控制环境亮度与降水。冬季才能选择雪天。首阶段选项立即切换，水色逐渐过渡；完整的灯光、材质和粒子过渡列入第二阶段。首阶段雨雪为粒子概念验证，尚未实现地面湿润、积雪增长与水面雨滴。

桌面默认像素比最多 1.5，阴影 2048，水面反射 768；轻量模式像素比 1，阴影 1024，水面反射 256。后续基于实测帧率自动降级、共享几何、植被实例化与可见纹理加载。降低动态偏好时停止书签和粒子运动。性能目标为常规桌面 50–60fps、手机 30fps，需在真实设备测量，不能以构建成功代替性能验收。

## 内容实体

诗词信息查询优先使用古诗文网 https://www.gushiwen.cn，包括原文、诗人、朝代、注释、译文、背景、赏析与名句。每条资料记录实际采用的作品页链接、查询日期、核实状态和版本；仅有首页链接不代表作品已核实。访问失败或字段缺失时保持空值并说明缺失，不自动换来源。现代注释、译文与赏析采用自行概述并附来源，避免整段复制。用户提供的测试内容在完成核实前保持 pending。

Poem 包含稳定 id、schemaVersion、标题与别名、poetId、dynastyId、体裁、标签、按节按行的原文、名句、注释、译文、赏析、创作背景、出处、核实状态、素材、sceneHint、发布状态和排序。每行使用稳定 id，译文和名句关联行 id。背景时间、地点与文本允许 null，未知信息不推测填写。

Poet 单独维护姓名、朝代、字、号、生卒、简介和来源。Dynasty 维护名称与可选年代。后续增加 collections 策展、多个视觉版本、素材授权与版本历史。视频元数据可扩展尺寸、时长、帧率和多个清晰度。

## 目录职责

- src/app：应用入口与样式。
- src/domain：实体类型，后续增加完整 schema。
- src/services：索引、详情读取和统一资源 URL。
- src/features/poem-viewer：主图与单实例视频生命周期。
- src/scene：场景组合，environment、water、bookmarks 独立维护；后续拆出 architecture、lighting、vegetation、atmosphere。
- content/poems、poets：人工维护的 JSON，content/dynasties.json 为朝代列表。
- media-source/poems/诗词ID：原始 bookmark.png、artwork.png、motion.mp4。
- public/content、public/media：脚本生成的部署文件，不人工修改。
- scripts：素材整理与内容构建校验。
- demo：保留用户测试素材，不作为生产目录。

## 素材加载与缓存

首屏先读取小索引，再载入场景代码与书签缩略图。主图及视频只在选中时请求，详情请求支持 AbortController。原生视频渐进缓冲，不主动把所有媒体放入 Service Worker 缓存。生产视频采用 H.264 MP4 与 faststart，服务器必须验证 Range 请求返回 206。浏览器播放缓冲范围由浏览器决定，懒加载并不承诺只下载固定字节。

统一 VITE_MEDIA_BASE_URL 默认为 /media/。迁移 R2 只修改部署环境变量。当前素材固定文件名，缓存一小时；后续构建增加内容哈希，实现长期 immutable 缓存。大量诗词不能将全部纹理同时上传 GPU，第二阶段实现可见区加载和 LRU 释放。

## Cloudflare 部署

首版使用 Pages 静态部署，无 Functions、D1、KV。构建命令 npm run build，输出 dist。构建前必须准备 public/media；原始素材默认不入 Git，CI 应从私有素材存储下载或由本地构建后上传 dist。Pages 免费计划单文件上限 25MiB、文件数上限 20000。大视频或大量素材迁移 R2 Standard，其免费额度不等于无限免费，部署时检查实时配额。

参考：[Pages 限制](https://developers.cloudflare.com/pages/platform/limits/)、[R2 定价](https://developers.cloudflare.com/r2/pricing/)、[Three.js Water](https://threejs.org/docs/pages/Water.html)、[React Three Fiber 性能](https://r3f.docs.pmnd.rs/advanced/scaling-performance)。

## 开发阶段与验收

光效层位于 src/scene/lighting/AtmosphericLight.tsx，包含近似薄雾光束、GPU 微尘、受限强度的 Bloom 与暗角。光束采用透明几何与 shader，利用场景深度遮挡，属于体积光的视觉近似，不做完整体积散射或光线追踪。微尘与光束随时辰、天气变化，方向光轻微变化形成缓动阴影。轻量模式关闭后处理并减少光束和微尘数量；减少动态偏好时停止持续动画。光效只作用于 3D 场景，不改变诗画视频。

第一阶段：建立内容目录、导入测试诗、风动书签、廊架阴影、反射流水、环境选项、随诗入境、主图转视频；验证首屏零视频请求、点击延迟、循环、关闭释放、窄屏布局和静态构建。当前仅一首测试诗，不重复填充书签。

固定视角改进已加入分段和搜索；木石程序纹理与凹凸、圆木柱与细密栏杆、灯笼骨架与流苏、分枝树木与实例化叶片、起伏山体、石岸与芦苇均已加入。程序纹理便于本地维护，无外部资源依赖；仍需经过授权的扫描材质和艺术模型才能进一步达到写实画质。

第二阶段：真实河道、精细木石模型与 PBR 材质、天空与环境渐变、雨滴涟漪、花瓣叶片、积雪、自动性能分档、视频编码与资源版本化。加入更多诗词验证维护流程。

第三阶段：筛选、策展、诗人页、背景与解读阅读面板、独立诗词地址、键盘探索、真实手机性能与多浏览器验收。只在有明确需求时引入服务端。

### 移动端竖排阅读统一
移动端读诗与桌面右侧诗词共用 VerticalPoem 组件：诗名、朝代诗人、原文从右向左排列，使用毛笔字体和诗人印章。手机保留观画／读诗切换，窄屏调整字号列距；超长诗词可横向滚动，初始从右侧开始阅读。


### 红墙与墨染画卷
屋檐背景与相机固定，书签挂环保持固定，仅绳下书签及流苏随风摆动。底部诗名和分页去除纸托、底色和分隔线，改用浅暖色毛笔字融入红墙。手机正文调整为22–29px，诗名28–42px，保持右向左竖排。新增不规则墨染透明边缘与宣纸渐进晕染；画卷约1.05秒横向展开，木轴保持圆形，展开后半秒启动视频。遵循减少动态效果设置。


### 统一展开与纤维渗墨（替代独立 CSS 动画）
卷轴由一个逐帧进度驱动：两侧画轴移动旋转、纸张顶点揭开、HTML画面裁切共用同一显露宽度。纸张UV保持原始比例，边缘轻微卷曲。主图就绪才启动一次约1.25秒展开，完成回调后等待500ms播放视频。切换读诗不重启展开。纸面晕染改为材质中的多尺度纤维噪声、毛细渗透前沿和边缘积墨，展开后约5秒渐进，中央阅读区抑制染色。旧的色块 SVG 和分段 CSS 展开动画不再参与渲染。
