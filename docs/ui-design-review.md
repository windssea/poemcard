# 整体界面优化记录

采用 design-taste-frontend 的保留式改版流程。界面是中国古典诗画庭院，已有红墙、旧宣纸、毛笔标题与宋体正文构成品牌语言；本轮优化聚焦层级、间距、操作集中和可读性，不改变导航名称、背景构图、内容路径或两端阅读方式。

## 设计审视

原有问题是底部诗名与分页分散、小字过小和偏淡、照片上的说明文字缺乏稳定背景、手机面板触控区域偏小，以及多轮 CSS 覆盖导致维护困难。保留固定视角、书签风动、层叠枝花、偶发飞鸟、宣纸墨染、桌面左画右诗和手机观画读诗切换。

设计参数采用 DESIGN_VARIANCE 6、MOTION_INTENSITY 5、VISUAL_DENSITY 2。布局保持非对称构图，动态由庭院承担，界面仅用简短的展开和触压反馈。使用项目原生 CSS 和已建立的字体体系，不引入新的通用组件视觉系统。纸色、墨色与朱砂色符合用户明确要求的古典纸画语境。

## 调整内容

- 诗名入口和分页合并为底部纸面浏览带，桌面一行、手机两行，长列表横向滚动。
- 竖排纸笺保留寻诗和境候，统一尺寸，场景时辰说明使用稳定纸面背景。
- 检索与环境面板统一标题、间距、输入框和选择状态，主要触控目标至少44px。
- 增加 Escape、点击空白收起面板，并将焦点恢复到对应入口。
- 增加内容加载和检索空结果的明确提示。
- 夜景标题改为浅墨纸色，面板和阅读区域维持浅纸主题。
- 保留视频完整比例且无独立边框，提升阅读字号与工具按钮的可读性。
- 清理旧的 courtyard.css 与累积样式覆盖，结构在 styles.css，视觉在 ink-ui.css，阅读布局在独立模块。
- 修复热更新重复创建 React 根节点的问题，复用热更新保存的根节点。

## 验证范围

检查1440×900桌面和390×844手机的庭院、检索、境候及读诗页面；验证检索空结果、Escape收起、视频播放与阅读暂停。视频仍为 contain。主要文字相对纸面计算对比度9.63:1，说明文字5.33:1，朱砂文字6.02:1，输入提示5.25:1。背景照片局部亮度变化仍以实际视觉检查为补充。

内容与布局测试、TypeScript和生产构建通过。真实手机性能、完整屏幕阅读器流程和现场发布后的加载指标尚未测量。现有静态站只有一个入口，无既有排名页面或URL迁移；本轮未改动标题和内容路径。
