# 庭院环境互动设计

后续已加入远山／建筑分离与江南景窗第二主题，主题、遮罩、挂点和天气空间关系见 [双庭院设计](scene-design.md)。以下积水物理与去固有光影规划仍适用。

## 渲染分工

保持固定正交视角。建筑、红墙和石板以高精度分层图像提供纹理；书签、宫灯、月亮使用真实几何；花枝用透明材质、局部顶点形变；积水涟漪、云影、湿润和光色由着色器驱动。没有用低精度屋檐模型覆盖原图，也不以自由相机展示缺少背面细节的布景。

当前加入的素材均使用内置 imagegen 对原分层图编辑，保留构图、瓦面位置、墙边和石板透视。它们是重绘变体，不是无损分割，切换中可能有细微纹理变化。生成后保存进仓库目录，构建转换 WebP。

| 层 | 当前实现 | 空间与交互 |
| --- | --- | --- |
| 建筑与远山 | 正常、雨湿、冬雪对齐底图 | 同一背景坐标，逐渐混合；保留空红墙 |
| 瓦面与石地 | 冬季瓦沿雪堆、湿石浅积水 | 来自高精纹理，不增加方块雪帽或镜面地板 |
| 近景植物 | 春花、夏叶、秋季叶色、冬季覆雪裸枝 | z=1.6；挂根稳定，枝梢风动，轻微鼠标视差 |
| 书签 | 木轴、纸面、玉环、流苏及阴影 | 固定挂点，低频主摆加小幅次摆，流苏滞后 |
| 光照 | 时辰光色、强度、方向平滑变化 | 真实照明影响书签和宫灯，照片层同步光色 |
| 雨与水 | 细雨丝、湿润变体、七处不规则时序涟漪 | 涟漪限于地面UV区域，不涂到红墙上 |
| 远景气氛 | 分层云雾、飞鸟、墙面云影 | 远层慢、近层快；与书签点击无冲突 |

## 已实现的状态关系

统一入口为 `surface-state.ts`。时辰输出背景光色、环境光、主光强度与位置，建筑、天气变体和近景枝叶使用一致的昼夜色调。傍晚偏暖，雨雪与阴天偏冷且减少直射光，夜间降低曝光并保留宫灯和月光层次。主光与素材色调平滑过渡，避免切换按钮时突然跳色。

冬季选择即代表已有积雪的庭院，冬雪纹理逐渐显现；选择雪天气增加飘雪。换季后雪层慢慢淡出。它目前是美术预设，不是假装计算了真实雪厚、融雪流量或温度。

雨天湿层逐渐显现，地面浅洼保留粗糙石板和接缝，动态细涟漪在低处扩散。停雨后湿层缓慢消退，而不是瞬间变干。湿层中建筑倒影来自素材，不包含移动书签与宫灯的实时镜像；没有开启昂贵的全场景反射渲染。

春季开花、夏季换成真实绿叶素材、秋季仅对叶片做色素变化、冬季换成带积雪的裸枝。花瓣粒子只在春季出现；秋季采用叶片色，冬季无花瓣，雪天气显示雪粒。普通风摆与减少动态模式分开。

书签最大摆幅预留在分页算法中：手机0.024弧度、桌面0.085弧度。两个低频正弦按0.86/0.14混合，避免机械同步和突然抖动；玉环仍随纸轴，流苏响应稍快。布局预留相应摆动足迹，仍保持手机一排最多四张。

## 后续细化的正确顺序

1. **区域材质与去固有阴影**：给屋顶、墙、石板、远树建立注册遮罩；准备少固有光影的底图、粗糙度和高度图。照片已有的树影无法被真实太阳移动，当前动态投影只属于独立3D对象；要进一步模拟晨暮，必须先拆掉这部分固有阴影。
2. **轻量深度代理**：只为确有视差价值的瓦沿、墙角和地面建立与画面匹配的精细深度网格，轮廓藏在纹理下面，禁止粗糙模型露边。使用法线、粗糙度和低幅视差映射改善侧光，而不是盲目堆高面数。
3. **累计状态**：引入wetness、snowCoverage、snowDepth与surfaceTemperature；下雨填充低洼湿度，停止后蒸发，雪落在朝上的区域，灯旁融化较快。环境设置只是目标，表面状态有时间记忆，切诗不清空。状态先保存在当前会话；是否跨刷新保留再由产品需求决定。
4. **局部积水反射**：为少量固定水洼使用低分辨率反射相机，只捕获瓦沿、天空、灯与少数书签；手机关闭真实反射，保留图片倒影和程序波纹。降雨时用法线扰动模糊反射，晴夜保留低强度灯色，避免完整镜面地板。
5. **表面接触细节**：檐口滴水、滴落击水涟漪、墙脚潮痕、落叶停在干燥石面。发射位置来自屋檐遮罩与地面低洼图，数量有限，动态不遮挡诗签。

## 性能与维护

春日首屏仍只请求原背景与原花枝，新天气和植物纹理按首次选择加载，独立Suspense不阻塞已显示背景。首次加载后保留GPU纹理以平滑返回，当前三张前景、三张底图的RGBA原始内存约36MiB，实际含mipmap会更高；手机长期使用多种环境可后续增加闲置纹理淘汰。全屏画卷打开时庭院渲染暂停，减少动态模式关闭涟漪和风摆。

源素材在 `scene-source/layers`；生成脚本为 `scripts/prepare-scene.mjs`；天气材质在 `WeatherSurfaces.tsx`；季节花枝在 `BlossomForeground.tsx`；书签风摆与安全容量需一起维护。无新增模型、外部贴图CDN或首次打开时的视频请求。

## 生图提示词与素材来源

使用内置 image_gen 的 lighting-weather 编辑，非CLI/API路径。

- **courtyard-winter.png**：以courtyard-clean.png为目标，保持原画幅、机位、建筑坐标；仅增加向上瓦面、檐沿、脊兽、地面接缝的细腻积雪，远山轻雪、远树冬枝。红墙保持空白与原位置，不生成粒子、UI或书签。
- **courtyard-wet.png**：同一底图，仅改变湿润材质与柔和阴天光；瓦片细湿亮、墙脚潮痕、底部石板浅积水及柔和倒影。保留石缝，不生成镜面地板、雨粒或新物件。
- **blossom-winter.png**：以透明花枝为目标，原画幅与枝根位置不变，移除花叶，细裸枝上轻积雪，其余区域真实alpha透明。
- **blossom-summer.png**：同一透明枝花，花换为适量自然绿叶，保留枝根、空白和原尺寸；叶脉细腻，无塑料光泽，其余透明。秋色由材质处理，不额外下载秋季图。

完整实际提示词与透明参数记录在 `scene-source/environment-prompts.md`。所有选定输出均已复制到项目中；原始正常素材没有覆盖。
